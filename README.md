
# DataLens — Mini Data Analyzer 📊

DataLens is a beginner-friendly data analysis web application that helps users explore CSV datasets, view important statistics, and understand their data through interactive charts.

## ✨ Features

- Upload CSV files directly from your device
- View dataset dimensions: rows and columns
- Identify numeric columns and missing cells
- Preview the first 10 rows of a dataset
- Visualize numeric data using bar charts
- Calculate average, median, minimum, and maximum
- Try the built-in sample dataset
- Responsive interface for desktop and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Chart.js

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Click **Try sample dataset** to explore the demo.
4. Upload your own `.csv` file to analyze your data.

An internet connection is required to load the Chart.js library from its CDN.
